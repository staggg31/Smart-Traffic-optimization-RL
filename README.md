# Traffic Signal Optimization Using Reinforcement Learning

A simulation-based research project for adaptive traffic signal control using
SUMO, Python, TraCI, and reinforcement learning.

## Project goals

- Build a reproducible traffic simulation.
- Establish fixed-time and actuated baseline controllers.
- Train and evaluate an RL-based controller.
- Compare traffic efficiency and safety-related measures.
- Evaluate performance across traffic demand levels and random seeds.

## Research integrity

All reported results must come from actual simulation experiments.
Safety-related measures and limitations will be reported separately.
